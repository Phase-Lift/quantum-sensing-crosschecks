# Sensor commutator benchmark v0.2

A verified **conditional** pulse-control extension of the three-observer GHZ readout benchmark.

## Result

A 32-oscillator-pulse sequence yields

`Phi = 128 * beta * a^3 * b * q0 * g1 * g2 * g3 + O(beta^2)`

while removing the ordinary quadratic conditional loop phase and specified static longitudinal single/pair nuisance terms. An ordinary cubic actuator response is exactly indistinguishable in the retained pulse model. **This is not a hardware experiment or a sub-Planck observation.**

Read `CHECKPOINT.md` for the derivation, assumptions, scale conversion, failed attribution test and references.

## Run

```sh
python -m pip install -r requirements.txt
python commutator_controls.py --output .
```

Use normal Python, not `python -O`; tests use assertions. The defaults run 20,000 simulated experiments per hypothesis, each representing 100,000 three-sensor shots. The binomial sufficient statistic is sampled rather than enumerating every shot of every experiment. A separate raw 100,000-triple record is summarized in `raw_triple_counts.csv`.

The 32-, 48-, 64- and 96-dimensional oscillator checks multiply the pulse matrices themselves, independently of the closed-form phase. The model is first order in the phenomenological deformation; a separate fifth-power momentum correction checks sensitivity to the next order.

All reported numbers are generated by the included code. `results.json` records dependencies, checks, counts and configuration. The source does not access accounts, instruments, external APIs or the internet.
